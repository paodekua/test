# 第3章 因果律武器初显威

时间仿佛在这一刻被无限拉长。

那条散发着毁灭性高温的暗紫色“地狱炎龙杀”，犹如一颗坠落的陨石，咆哮着撕裂空气，距离张原野的脸庞仅剩最后五米。

看台上的惊呼声已经被极度的高温吞噬，所有人都瞪大了眼睛，等待着那个F级废柴在极致华丽的魔法中灰飞烟灭的壮观景象。

甚至连贵宾席上的凌楚汐，都已经微微抬起了雪白的下巴，准备对这场毫无悬念且毫无美感的闹剧进行最后的宣判。

然而。

在这万众瞩目、充满了创世神法则那绝对“逼格”与“毁灭美学”的庄严时刻，张原野做了一个让全场三千名师生集体怀疑人生的动作。

他极其淡定地、一口将那根剥开的香蕉塞进了嘴里。

“吧唧，吧唧。”

咀嚼声在震耳欲聋的龙啸中显得那么微不足道，却又因为他那张满是“清澈愚蠢”的脸庞，而显得格外刺眼。

紧接着，他随手一挥。

那块发黄发黑、软塌塌、还带着一丝诡异反光的香蕉皮，在空中划出一道极度缺乏抛物线美感的轨迹，轻飘飘地落在了张原野身前两米处的黑曜石地板上。

“这蠢货是被吓傻了吗？”赵天宇狂傲的笑声在魔法光辉的映衬下显得犹如神祇降临。

他双手维持着结印的姿势，整个人犹如踏空而行的战神，脚尖轻轻点在被高温融化的地板上，准备以最帅气、最无懈可击的姿势，欣赏对手被自己的最强一击化为灰烬。

就在他的战靴，或者说他那无敌的火系魔力力场，触碰到那块香蕉皮的瞬间。

整个宇宙的物理法则、魔法公式、甚至是创世神引以为傲的“绝对秩序”，在这一刻，仿佛被一只看不见的、充满了恶趣味的大手，狠狠地扇了一个大逼兜。

“啪叽。”

一声极度滑稽、甚至自带某种廉价喜剧音效的轻响，突兀地在赵天宇的脚底炸开。

那是【必定滑倒的香蕉皮】的因果律判定生效的声音。

下一秒。

原本不可一世、浑身缠绕着暗紫色火焰的赵天宇，突然感觉自己的右脚被一股完全无法抗拒、甚至不讲道理的力量猛地向前一拽。

他的身体瞬间失去平衡，原本完美符合黄金分割率的施法姿势，在不到零点一秒的时间内，扭曲成了一个极其诡异、极其反人类的“劈叉后仰”动作。

“卧……槽？”

赵天宇甚至连惊呼都没来得及发出，他那张写满了狂傲与逼格的脸庞，就以一种近乎“自由落体加火箭推进”的速度，狠狠地砸向了地面。

“砰！！！”

伴随着一声沉闷的巨响，那条原本足以毁天灭地的“地狱炎龙杀”，因为施法者的魔力回路瞬间崩溃，如同一个被戳破的巨大气球般，在空气中“噗”的一声化作了漫天毫无杀伤力的火星。

而赵天宇本人，则脸着地，在那块坚硬无比、刻满了防御法阵的黑曜石擂台上，如同一个失控的冰壶，硬生生滑行了足足十米远！

“呲啦——”

令人牙酸的摩擦声在死寂的竞技场内回荡。

直到他的脑袋“咚”的一声撞在了擂台边缘的防护结界上，这场极度离谱的“滑行”才终于停止。

整个中央巨型穹顶竞技场，死一般寂静。

三千名师生，包括那些高高在上的导师和S级天才，此刻全都像被施了定身咒一样，僵在原地。

他们看到了什么？

一个A级火系天才，在释放最强绝招、准备以最华丽的姿态秒杀对手时，因为踩到了一块……香蕉皮？

然后，以一种极其滑稽、极其粗鄙的狗啃泥姿势，滑行了十米？

这特么符合魔法定律吗？！这特么符合重力法则吗？！这特么符合创世神定下的“力量必须优雅”的绝对真理吗？！

“不……不可能……”贵宾席上，一直保持着冰山女神人设的凌楚汐，此刻瞳孔剧烈地震，那双原本冷漠的眼眸中充满了难以置信的荒谬感。她甚至下意识地抓紧了王座的扶手，指关节因为用力过度而微微发白。

而在监控室里。

“咔嚓！”

号称“铁面判官”的S级雷系教导主任李严，硬生生捏碎了手中那个由千年寒铁打造的保温杯。滚烫的茶水洒了他一身，但他却毫无察觉，只是死死盯着屏幕上那个趴在地上不知死活的赵天宇。

擂台上。

张原野依然站在原地，慢条斯理地咽下了最后一口香蕉。

他看着不远处呈“大”字型趴在地上的赵天宇，无奈地摇了摇头。

“都说了让你别上火了，看吧，脚底打滑了吧。这破学校的地板也太滑了。”

他那极其无辜、清澈愚蠢的语气，在寂静的竞技场中回荡，仿佛是对这个世界所谓的“秩序与逼格”最致命的嘲弄。

就在这时，张原野的视网膜上，那块只有他能看到的淡黄色系统面板，如同疯了一般开始疯狂刷屏，闪烁出刺眼的红光：

【叮！！！】

【系统判定生效！因果律武器触发成功！】

【检测到宿主在极度严肃的场合（期中实战考核），做出了极度离谱且破坏秩序的行为（用香蕉皮滑倒A级天才）！】

【现场目击人数：3000人！（含S级异能者及高阶导师）】

【当前场景严肃度：50！（极度崇尚华丽破坏力的对决）】

【行为离谱指数：80！（无视魔法免疫，强行物理狗啃泥）】

【收益计算中……】

【恭喜宿主！获得荒诞值（AP）：12,000,000点！！！】

看着面板上一长串的零，张原野原本毫无波澜的嘴角，终于忍不住微微上扬。

而此时，擂台边缘的赵天宇终于从那“0.5秒脑干缺失级眩晕”中缓过神来。

他颤抖着双手撑起上半身，那张原本英俊狂傲的脸，此刻已经肿成了猪头。

“噗……”

他一张嘴，伴随着一口混合着尘土的鲜血，两颗白花花的门牙掉落在了黑曜石地板上。

“你……你到底对我做了什么……”赵天宇漏风的声音里充满了无尽的恐惧和崩溃，他那引以为傲的火系魔力，此刻因为极度的心理阴影，连一朵小火苗都搓不出来了。

张原野走到他面前，居高临下地看着他，从兜里又掏出了一把塑料梳子，认真地梳了梳自己乱糟糟的头发。

“没做什么啊。”张原野收起梳子，眼神清澈得像个刚入学的幼儿园新生，“只是请你吃了个香蕉皮而已。这可是纯天然无公害的植物系异能，你看，连魔法反噬都没有，多环保。”

说完，他转过身，在一片死寂中，慢悠悠地走下了擂台。

在这个被创世神规定了“不准搞笑”、“只有华丽魔法才是真理”的世界里。

张原野，用一块香蕉皮，硬生生砸碎了他们引以为傲的神坛。
