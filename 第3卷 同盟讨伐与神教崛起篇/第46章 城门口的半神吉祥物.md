# 第46章 城门口的半神吉祥物

香蕉城的城门口，如今多了一件“镇城之宝”。

那不是传说中的上古神器，也不是同盟的旗舰主炮残骸，而是一个被捆成粉红色蝴蝶结、挂在合金门框上的男人。

男人赤裸着上半身，肌肉像是用星核铸出来的，每一寸都写着“我很能打”。可他的表情却像是被宇宙级社死砸过一遍——翻着白眼，嘴角还残留着一点泡沫，额头上贴着一张不知道谁塞上去的黄色便利贴。

便利贴上写着四个大字：禁止逃课。

城门外排队的人很长，从黑街十三号原来的臭水沟一路排到新修的“香蕉大道”。队伍里有海盗、有赏金猎人、有走私商人，也有穿着皱巴巴便装、却把武器藏在衣领里的边缘异能者。所有人都在一个窗口前交钱，领一张印着香蕉图案的纸票。

票面上写着：

【半神吉祥物参观券】  
【附赠：与半神合影一次（不包笑）】  
【备注：摸一次肌肉加收两百信用点】

窗口后面坐着一个叼着棒棒糖的清道夫宝宝，他看着人流，认真地把钱塞进一个写着“香火箱”的铁皮桶里，动作笨拙却莫名庄严。

“下一位！”他用稚嫩的声音喊。

“教主真的太会做生意了。”队伍里有人小声嘀咕，语气里却是服气，“以前在混乱星环，谁能想到半神这种东西也能收费参观？”

“别乱说。”旁边另一个老海盗瞪了他一眼，“这叫信仰体验项目。你不懂。”

“我不懂？”那人压低声音，“我只知道我昨天笑到肚子抽筋，今天还在疼。”

“那你更得买票。”老海盗一本正经，“疼说明你笑得真，这是真修行。”

广场上甚至有人拉起了摊位，卖起了各种“半神周边”。

“来来来，正宗半神同款粉红蝴蝶结！一根只要三十信用点，买三送一！”  
“半神跳舞教程芯片！高清无码，高清无码！”  
“半神同款口吐白沫纪念喷雾！喷一下就能体验‘神威’！”

萧锦妍站在城门上方的瞭望台，面无表情地看着下面这一幕，手里翻着一本账册。她的职业套装依旧笔挺，发丝一丝不乱，只有那双眼睛里，藏着一种财阀千金才懂的兴奋。

“参观券、周边、摊位租金、合影加价、摸肌肉加价……加上今天进城税与停泊费，现金流已经稳定了。”她合上账册，转头看向身边的沈柚宁，“你那个‘香蕉城税则’我已经拟好了，等教主签字就能执行。以后这地方不是黑街，是国。”

沈柚宁正蹲在城门后的一堆金属废墟里，像拆玩具一样拆着同盟舰队的残骸。她戴着护目镜，白大褂袖口卷到手肘，手指在一块块晶体和线路之间穿梭，神情近乎狂热。

“税则你自己定。”沈柚宁头也不抬，“我更关心另一件事。”

“什么？”萧锦妍问。

沈柚宁把一枚被烧得发黑的核心晶体举起来，上面还残留着同盟的徽章。她把晶体贴近检测仪，屏幕上跳出一串让人头皮发麻的数值。

“同盟的轨道炮不是单纯的能量武器。”她声音很轻，却像刀，“它包含一种‘规则约束’的结构。那是把‘秩序’写进能量里的东西。我们这次靠蹦床反弹赢了，但同盟不会一直用同一套打法。”

萧锦妍皱眉：“你怀疑他们会用更不讲道理的手段？”

“不是怀疑，是确定。”沈柚宁把晶体丢回废墟，“那帮人最擅长的不是火力，是定义世界该怎么运转。他们要是真的认真起来，可能会从根本上否定教主的荒诞。”

“否定？”萧锦妍下意识看向城门口那位半神吉祥物。

就在她目光落下的瞬间，那位被捆成蝴蝶结的男人，睫毛轻轻抖了一下。

下一秒，他猛地睁开眼。

那双猩红的眼眸一醒来就充满了暴戾，像两团要吞噬星海的火。他的第一反应不是求生，而是屈辱。

他看见了自己的姿势。

他看见了自己的蝴蝶结。

他看见了城门外排队的人群、摊贩、以及那块“禁止逃课”的便利贴。

拉达曼迪斯的呼吸停了一瞬。

然后，整个香蕉城的空气都像是被他一口气吸干了。

“张——原——野——”

他的声音像是从地狱里挤出来的，带着足以震碎舰队的狂暴。城门口的游客还没反应过来，就感觉脚下一软，膝盖发抖，许多人直接跪在地上。

“他醒了！”有人惊叫。

“别慌！”一个老信徒嘶吼，“教主说了，醒了也别怕，他还欠我们三小时舞费！”

拉达曼迪斯的神力开始翻涌，猩红色的领域像火一样扩散。他试图震断那粉红蝴蝶结，可那玩意儿不讲道理——它不是绳子，是一种“你被捆住了”的因果。

他越挣扎，蝴蝶结越紧。

他咬牙，眼眸里闪过决绝。

他打算自爆。

半神自爆不是死，是把自己的神格炸碎，宁愿毁掉本源，也要带走这一切耻辱。

就在他准备引燃神格的瞬间，城门上忽然传来一个熟悉的、欠揍到极点的声音。

“哟，醒啦？”

张原野穿着一件印着大香蕉的花衬衫，趴在城门栏杆上，手里还端着一串烤香蕉。他咬了一口，慢慢嚼，像看热闹一样看着下面。

“别急着炸啊。”他很认真地劝，“你要是把自己炸了，我们周边就不好卖了。”

拉达曼迪斯的眼角狠狠抽了一下，血泪差点当场飙出来。

“你这个异端……你侮辱了神……”

“别扯神。”张原野摆摆手，“你现在是吉祥物，吉祥物要有吉祥物的自觉。来，笑一个，给游客留个念想。”

“我不——”

拉达曼迪斯刚想咆哮，身体却像突然回忆起某段恐怖的肌肉记忆。

他全身一抖。

他的腰不受控制地轻轻扭了一下。

城门外的人群先是一愣，随即爆发出比刚才还要热烈的欢呼。

“动了！半神动了！”  
“哈哈哈哈！他要复跳了！”  
“快！拍！别让他停！”

萧锦妍闭上眼，深吸一口气：“他醒了也能继续带货……这世界真的疯了。”

沈柚宁却没有笑。她的目光越过人群，落向远处的星空。那一刻，她的检测仪忽然发出一声短促的蜂鸣。

屏幕上跳出一行字：  
【检测到规则级波动：秩序向量上升】  
【来源：同盟核心深处】  
【等级：无法评估】

沈柚宁的指尖停住，声音压得极低：“来了。”

张原野还在城墙上啃香蕉，像是没听见一样。他看着下面那位半神，忽然笑了笑，嘴角有点冷。

“来就来呗。”他说，“他们要是敢把‘不准笑’写进规则里，我就把‘不准装’写回去。”

他说完，抬头看了一眼天空。

星海深处，一道细得像针的白光，悄无声息地亮了一下，又迅速隐去。

像有人在宇宙最上层的棋盘边，轻轻落了一子。
