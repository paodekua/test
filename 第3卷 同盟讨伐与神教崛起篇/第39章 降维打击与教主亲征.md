# 第39章 降维打击与教主亲征

“糖糖！我要糖糖！！！”

五个被降智的清道夫发出震耳欲聋的欢呼声。他们手里各自拎着一把造型极其滑稽、颜色极其鲜艳的红黄色塑料充气大锤。

这可是张原野花了血本兑换的【百分百被空手接白刃的充气大锤（团购量产版）】。

“轰！”

没有任何多余的动作，五个清道夫如同五枚人形核弹，直接踩碎了基地院子里的黑曜星铁地板，化作五道灰色的残影，以一种完全无视重力和空气阻力的恐怖速度，直冲云霄！

天空中。

真理秩序同盟的十二艘重型星际战列舰主炮已经充能完毕。耀眼的幽蓝色能量在炮口汇聚，周围的空间都在这股毁灭性的力量下微微扭曲。

“开火！给我把那座破房子连同那五个疯子一起蒸发掉！”修斯少将站在舰桥上，面容扭曲地嘶吼着。

“长官！雷达锁定失败！那五个目标的移动轨迹完全违背了物理学定律！他们……他们太快了！”火控军官绝望地大喊。

下一秒。

“砰！”

旗舰“圣裁号”巨大的全景落地窗外，突然出现了一张贴在玻璃上、极其清澈愚蠢、甚至还流着口水的脸。

一个清道夫像个壁虎一样趴在战舰的防护罩上，手里举着那把画着笑脸的充气大锤，隔着玻璃冲着里面的修斯少将露出了一个极其灿烂的、属于三岁孩童般的纯真笑容。

“大铁块，碎！”

清道夫含糊不清地嘟囔了一句，然后极其随意地，挥动了手中的充气大锤。

“吧唧。”

伴随着一声极其轻佻、仿佛踩到橡皮鸭子般的音效，那把看似毫无杀伤力的充气锤，轻飘飘地砸在了足以抵御陨石撞击的战舰能量护盾上。

时间在这一刻仿佛静止了。

修斯少将和舰桥里的所有军官，眼睁睁地看着那层代表着同盟最高科技结晶的S级能量护盾，在充气锤落下的瞬间，像是一层脆弱的肥皂泡，无声无息地……破灭了。

紧接着，因果律效果轰然爆发。

“咔嚓咔嚓咔嚓——”

长达数千米的重型战列舰，那由高强度合金打造的舰体，竟然从被锤子击中的地方开始，出现了密密麻麻的龟裂。不到一秒钟，整艘战舰就像是一块被捏碎的饼干，在半空中解体了！

没有剧烈的爆炸，没有火光冲天。

战舰就像是突然失去了所有的结构强度，变成了一堆散落的废铁，稀里哗啦地往下掉。

“这……这不可能！！！”修斯少将在失重状态下疯狂地催动S级光系异能，试图稳住身形，他的三观在这一刻彻底崩塌了。

一把塑料充气锤，一锤子砸碎了一艘重型战列舰？这特么是哪个维度的宇宙法则？！

但这还不是最离谱的。

就在战舰解体、修斯少将和无数同盟士兵在半空中疯狂坠落的时候，充气大锤的第二个因果律效果触发了。

“扑通！扑通！扑通！”

天空中，所有被锤子波及的同盟军官和士兵，包括那位不可一世的修斯少将，突然感觉到一股极其霸道、完全无法抗拒的力量控制了他们的身体。

他们在半空中，以一种极其屈辱的姿态，双膝跪虚空，双手死死地合十高举过头顶，摆出了一个极其标准的“空手接白刃”姿势！

“好汉饶命！！！”

修斯少将那张英俊的脸涨成了猪肝色，他眼泪狂飙，屈辱地发现自己那引以为傲的S级异能在这股力量面前就像是个笑话。他只能和周围上万名士兵一起，在半空中一边下坠，一边用这辈子最大的音量，声嘶力竭地喊出这四个字。

“好汉饶命！！！”
“好汉饶命！！！”

上万名同盟正规军，在半空中整齐划一地跪着，一边自由落体一边高喊“好汉饶命”。这场面，简直比十个S级禁咒同时爆炸还要让人震撼。

而另外四个清道夫，也已经冲到了其他战列舰的面前。

“打地鼠咯！大哥哥说打下来有糖吃！”

“吧唧！”“吧唧！”“吧唧！”

伴随着一阵阵极其滑稽的音效，天空中剩下的十一艘重型战列舰，就像是一个个巨大的气球，被五个拿着充气锤的“三岁小孩”极其轻松地一艘艘敲碎。

漫天的废铁和跪着高喊“好汉饶命”的同盟士兵，像下了一场极其荒诞的暴雨，稀里哗啦地砸在了混乱星环的垃圾堆里。

黑街外围。

那几千名刚刚交了投名状、加入香蕉神教外围的亡命之徒，此刻全都张大了嘴巴，连手里的激光枪掉在地上都没发觉。

独眼龙狠狠地扇了自己一巴掌，确信自己不是在做梦。

他看着那些平日里高高在上、把他们当成垃圾一样清理的同盟精锐，此刻像下饺子一样掉在地上，还保持着极其屈辱的跪姿。

“咕咚。”独眼龙艰难地咽了一口唾沫，眼神中的震惊逐渐转化为了极其疯狂的狂热。

“教主万岁！！！”他突然声嘶力竭地大吼了一声。

“香蕉神教万岁！！！”
“干翻同盟！教主牛逼！！！”

上千名亡命之徒彻底沸腾了。他们终于明白，自己加入的不是什么邪教，而是一个真正能够把那些高不可攀的正统阶级踩在脚下的、无敌的神仙组织！

基地内。

沈柚宁推了推眼镜，极其冷静地在键盘上敲击了最后一行代码。

“教主大人，刚才的画面，我已经通过‘全宇宙广播大喇叭’的频率，强行切入了同盟的官方新闻频道，进行了全宇宙无死角直播。”她那张三无脸上闪过一丝狡黠，“现在的收视率，已经突破了三百亿。”

“干得漂亮，柚宁。”

张原野极其满意地看着天空中那场已经接近尾声的“打地鼠”游戏，听着外面那些狂热的欢呼声。

他慢吞吞地走出堡垒，来到那个被砸出的大坑边缘。

坑底，修斯少将满身灰尘，虽然凭借着S级异能没有摔死，但依然保持着“空手接白刃”的屈辱姿势跪在地上。他的眼神已经失去了往日的高傲，只剩下深深的恐惧和绝望。

张原野居高临下地看着他，剥开一根香蕉，将香蕉皮极其随意地扔在了修斯的头上。

“修斯少将是吧？第一波讨伐军指挥官？”

张原野咧嘴一笑，那笑容在修斯眼里简直比恶魔还要恐怖。

“回去告诉你们同盟的那些老古董。香蕉神教，今天正式接管混乱星环。”

“如果他们还想玩，我随时奉陪。”

“不过下次，记得多带点高阶材料来。我们基地的厕所，还缺几块星耀铁铺地板呢。”
